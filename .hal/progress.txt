## Codebase Patterns
- Claude Code commands are plain .md files in Commands/ — no YAML frontmatter; install.sh copies them to ~/.claude/commands/
- ${CLAUDE_SESSION_ID} is the built-in template variable for Claude's session ID; use $ARGUMENTS for user-supplied text
- Use Python (not jq/bash) for JSON manipulation — available on macOS by default and safer for nested structures
- Session entries always include: id (uuid4 lowercase), agent, session_id, working_dir, title (≤60 chars), note, priority, status, created_at (ISO8601 UTC), resume_cmd
